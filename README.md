# 역사재판 (History Judgement)

초등 5학년 역사 수업용 법정 추리 웹게임. 역전재판을 참고한 오리지널 게임으로, 사료를 증거로 역사 인물의 증언을 따지고 판결문을 씁니다.

**바로 플레이:** https://jodaehyeon4-debug.github.io/HistoryJudgement/

| 사건 | 제목 | 피고 | 자리 | 새로 배우는 장치 |
|---|---|---|---|---|
| 1 | 백제는 왜 무너졌나 | 의자왕 | 검사 | 추궁·조사 (튜토리얼) |
| 2 | 왕검성의 밤 | 위만 | 검사·변호인 | 두 증거 맞대기, 잠긴 구역 |
| 3 | 한강의 배신 | 진흥왕 | 변호인(기본)·검사 | 접견, 검사 논고 추궁, 혐의 취하 |
| 4 | 포석정의 그림자 | (숨은 피고) | 검사 | 숨은 피고 |
| 5 | 텅 빈 궁궐 | 최우 | 판사 | 판사 모드, 피고 바꾸기 |
| 6 | 두 얼굴의 왕 | 광해군 | 변호인 | 버릇 살피기 |
| 7 | 남한산성의 겨울 | 인조 | 검사 | 자기 혐의 내려놓기 |
| 8 | 장부 속의 이름 | 김 대감(가상) | 판사 | 헌법 카드, 증거 확대 |
| 9 | 닫힌 문 | 흥선대원군 | 셋 중 고르기 | 역할 고르기, 판단 보류 |
| 10 | 독립문 앞의 남자 | 이완용 | 검사·판사 (변호인 잠금) | 시리즈 결말 「붓을 든 자」 |

사건 4~10의 그림 가운데 아직 받지 못한 것은 코드 그림(인물)과 스케치(장소)로 대신합니다.

## 교사용
- 첫 화면에서 학생이 **번호나 별명**을 적으면(이름은 쓰지 않음), 조사·추궁·판단 기록이 그 기기 안에만 쌓입니다.
- 위쪽 **교사용** 단추 → 학생별 요약(며칠째, 가장 많이 헤맨 곳, 가장 많이 틀린 곳, 피고 인상 변화)과 **CSV 내려받기**, 사건별 고증 확인 목록.

## 폴더
| 위치 | 내용 |
|---|---|
| `index.html` | 게임 페이지 |
| `assets/` | 그림 파일 (배경 `bg/`, 인물 `sprites/`, 책상 `desk/`, 증거 `ev/`) |
| `src/` | 원본 코드. 사건 3부터 `storyN.js` 한 파일씩, 공통 틀은 `cases.js` |
| `src/tests/` | `solver.js`(사건을 처음부터 끝까지 혼자 플레이), `overlap.js`(단서가 인물에 가려졌는지) |

## 고칠 때 (Claude Code 등)
자세한 것은 `CLAUDE.md`를 보세요. 요약하면 `src`에서:
1. 새 그림: `python add_assets.py <받은 그림 폴더>` → `python make_assets.py`
2. `python build.py` → `python split_build.py` → `dist/index.html`을 맨 위 `index.html`로 복사
3. `node tests/solver.js c1` 등 20갈래와 `node tests/overlap.js`

※ 재판장, 검사, 변호인, 피고, 증인의 대사는 상상으로 만든 것입니다. 증거 카드는 실제 사료를 바탕으로 했고, 고증 확인 중입니다. 사건 8의 ‘김 대감’, 시리즈의 ‘기록관’과 가짜 기록들은 게임 속 상상입니다.
